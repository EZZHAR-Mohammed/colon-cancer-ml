How it works

01

Data Loading

62-patient colon cancer gene expression dataset (~2000 features) is loaded and standardised.

02

Forward Feature Selection

Iteratively selects the top 10 genes that maximise Logistic Regression accuracy.

03

Model Training

Final model trained on only the top 6 genes using 80/20 stratified train-test split.

04

Live Prediction

Enter expression values, the API scales and classifies them as Normal or Abnormal.
